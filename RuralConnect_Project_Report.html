1 Executive Summary & Problem Formulation

Rural school ecosystems encounter acute systemic challenges: severe network latency, intermittent electrical power, wide age and digital-literacy disparities among students, and total disconnect between teachers and rural parents.

RuralConnect resolves these issues through a zero-friction, offline-resilient digital platform:

🌟 Core Value Propositions
  • 3-Way Code Linking: Eliminates email/phone barriers for children. Teachers distribute Class Codes to enroll students; students receive unique Parent Codes to connect their parents.
  • Dual-Band Adaptive UI Engine: Primary mode (Class 1–5: playful sunny yellow theme, mascot voice, animal avatars) dynamically transitions to Secondary mode (Class 6–10: focused dark STEM workbench) based on grade selection.
  • Interactive SVG Graph Progress Reports: Parents review live score trend charts, completion percentages, test marks, and teacher remarks with built-in voice read-aloud support.
  • Village-Contextual Practical Activities: Science and math concepts are paired with hands-on village experiments using clay pots, courtyard tulsi leaves, and solar shadows.

3 Architectural Design & 3-Way Code Linking

The platform links three distinct user roles without requiring email addresses or phone verifications for students:

[👩‍🏫 TEACHER] -> Creates Account -> Generates Unique ClassCode (e.g. L4N3Z6)
                                        |
                                        v
[🎒 STUDENT] -> Enrolls with ClassCode -> Receives Unique ParentCode (e.g. J69QMA)
                                        |
                                        v
[👨‍👩‍👧 PARENT] -> Enters ParentCode -> Sees "Welcome, Parent of [Child]!" + Live Graph
🔐 Code Security & Uniqueness Rules
  • Alphabet: 30 unambiguous uppercase letters and digits (omits confusing 0/O and 1/I).
  • Collision Avoidance: Generated with crypto-random entropy and indexed as unique, sparse in MongoDB.
  • Access Isolation: Teachers only view students enrolled in their classes; parents only view reports for linked children.

4 Database Models & Schemas

User Schema (`server/models.js`)

Polymorphic model accommodating students, teachers, and parents:

name: String (Required) rollNo: String (Login ID / Phone, Unique, Lowercase) passwordHash: String (Bcrypt Salted) role: 'student' | 'teacher' | 'parent' grade: Number (1–10) classCode: String (Teacher unique, sparse) teacherId: ObjectId -> ref 'User' (Student's teacher) parentCode: String (Student unique, sparse) childIds: [ObjectId -> ref 'User'] (Parent's linked children) xp: Number, stars: Number, streakDays: Number
Content & Tracking Collections
  • Lesson: Stores slides (JSON deck) and practicalActivity (village experiment steps).
  • Quiz: Contains question bank with options, correctIndex, hints, and durations.
  • QuizAttempt: Tracks student test submissions, auto-scores, teacher evaluated marks, and remarks.
  • LessonProgress: Tracks slide reading completion and first-time XP rewards.
  • Announcement: Holds notices broadcast by teachers to specific classrooms.

5 Detailed Feature Breakdown

5.1 Adaptive Landing & Authentication (`AuthPage.tsx`)

  • Village Hero Illustration: High-definition SVG depicting rural village study spaces.
  • Chintu Mascot Bar: Features the friendly mascot with 🔊 Hear Chintu Speak voice button.
  • Streamlined Roles: Teachers enter only Name, ID, and Password. Parents enter Name, Phone, and Password. Students choose their class (1–10) and animal buddy.
  • Live Interactive Card Preview: Real-time animated card rendering the student's passport or teacher badge.

5.2 Teacher Classroom Console (`TeacherPortal.tsx`)

  • Assigned Classrooms: Clean grid cards showing Grade, Subject, Class Code, and enrolled student counts.
  • Student Roster & Activity Modal: Detailed activity completion table with streak days, quiz averages, and practical activity logs.
  • Study Material Upload: Article and slide publishing interface with village-context practical experiment steps.
  • Test Builder: Objective assessment creator with dynamic multiple-choice questions, correct answer pickers, and explanations.

5.3 Parent Portal & Visual Graph (`ParentPortal.tsx`)

  • Single-Code Child Connect: Connects to child using the 6-character Parent Code alone.
  • Welcome Greeting: Displays "Welcome, Parent of [Child Name]! 🎉" with avatar, grade, and school hub.
  • Dynamic SVG Score Trend Graph: Plots student's real test percentages over time with smooth area gradients, tooltips, and a 75% target line.
  • Voice Accessibility: 🔊 Listen in Voice reads progress aloud using the browser's speech synthesis engine.

6 REST API Endpoint Specifications

Method Endpoint Role Access Description
POST /api/auth/register Public Registers student, teacher, or parent. Generates codes.
POST /api/auth/login Public Authenticates credentials and returns 7-day JWT.
GET /api/auth/me Authenticated Restores session profile from Bearer token.
GET /api/teacher/classes Teacher Returns list of classrooms assigned to teacher.
GET /api/teacher/students Teacher Fetches students enrolled in the teacher's class.
POST /api/teacher/lessons Teacher Uploads study materials, slides, and practical activities.
POST /api/teacher/quizzes Teacher Creates chapter tests and multiple-choice questions.
POST /api/parent/link Parent Links child to parent profile via unique Parent Code.
GET /api/parent/children/:id/report Parent Returns live progress report, completed lessons, marks, and graph history.
POST /api/quizzes/:id/attempt Student Submits test answers, calculates score, and awards XP.

7 Execution & Deployment Guide

# 1. Install project dependencies npm install # 2. Configure server/.env file MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/ruralconnect JWT_SECRET=your_secure_jwt_secret_key PORT=5000 # 3. Seed initial curriculum (Optional) npm run seed # 4. Start backend REST API npm run server # 5. Start frontend Vite development server (New terminal) npm run dev

The frontend will be accessible at http://localhost:3000 and the backend API at http://localhost:5000.
